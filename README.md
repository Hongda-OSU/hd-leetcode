# hd-leetcode

A personal site that tracks my daily LeetCode practice.

## Getting Started

### Prerequisites

- Node.js 24+
- pnpm 12+

### Installation

```bash
git clone https://github.com/Hongda-OSU/hd-leetcode.git
cd hd-leetcode
pnpm install
```

## Usage

```bash
pnpm dev     # start the dev server
pnpm test    # run unit tests
pnpm check   # type-check
pnpm build   # production build
```
